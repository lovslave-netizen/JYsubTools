# 간단한 동영상 플레이어 프로젝트

## 목적

개인용으로 사용할 간단한 동영상 플레이어를 직접 제작한다.

기존 동영상 플레이어에서 원하는 단축키가 제대로 작동하지 않거나,
특히 방향키 조합이 일부만 먹는 문제를 피하고,
영상 감상과 삭제/정리 작업을 빠르게 할 수 있도록 만든다.

---

## 핵심 기능

### 1. 재생목록

- 폴더를 열면 동영상 파일들을 재생목록으로 구성
- 현재 재생 중인 영상 표시
- 이전/다음 영상 이동
- 영상 재생이 끝나면 기본적으로 다음 영상으로 이동
- 랜덤 재생 모드 지원

### 2. 영상 삭제

`Del`

- 현재 보고 있는 영상을 삭제
- 재생 중인 파일은 Windows에서 바로 삭제가 막힐 수 있으므로
  **다음 영상으로 먼저 전환한 뒤 현재 영상을 삭제**
- 삭제 후 다음 영상 계속 재생
- 가능하면 휴지통으로 보내는 방식 권장

예:

    01.mp4  ← 현재
    02.mp4
    03.mp4

    Del

    02.mp4  ← 재생
    03.mp4

    01.mp4 → 삭제

### 3. 재생목록 이동

- `PgUp` → 이전 영상
- `PgDn` → 다음 영상

랜덤 재생 모드에서는 다음 영상 선택을 랜덤으로 처리할 수 있도록 한다.

---

## 단축키

### 재생 위치 이동

- `← / →` → ±5초
- `Shift + ← / →` → ±10초
- `Ctrl + ← / →` → ±30초
- `Ctrl + Shift + ← / →` → ±1분

**중요:** 왼쪽 방향키뿐 아니라 오른쪽 방향키 조합도 동일하게 확실히 작동하도록 직접 처리한다.

### 영상 관리

- `PgUp` → 이전 영상
- `PgDn` → 다음 영상
- `Del` → 현재 영상 삭제 → 다음 영상 재생

### 랜덤 / 회전

- `R` → 랜덤 재생 ON/OFF
- `P` → 오른쪽 90° 회전
- `Shift + P` → 왼쪽 90° 회전

회전은 원본 영상을 재인코딩하지 않고 플레이어 화면에서만 적용한다.
가능하면 영상별 회전 상태를 기억한다.

### 기본 조작

- `Space` → 재생/일시정지
- `F` → 전체화면
- `Esc` → 전체화면 해제

---

## 1차 버전에서 굳이 넣지 않을 기능

일단 위 기능만 구현한다.

사용하면서 필요한 기능이 생기면 그때 추가한다.

추후 후보:

- `M` → 음소거
- `0~9` → 영상의 특정 위치로 이동
- 재생 속도 조절
- 화면 비율/크기 조절
- 기타 필요한 단축키

## 개발 방향

Python 기반으로 제작.

추천 조합:

- Python
- PySide6 → GUI
- VLC 계열 재생 엔진 → 동영상 재생

목표는 최종적으로 Windows에서 더블클릭하여 실행할 수 있는 EXE 형태.

개인용 프로그램이므로 불필요하게 복잡한 기능이나 배포용 기능은 넣지 않는다.

---

## 중요한 설계 포인트

1. 키보드 단축키는 플레이어 기본 단축키에 의존하지 않고 직접 처리한다.
2. `←`, `→` 및 Shift/Ctrl 조합을 모두 동일하게 지원한다.
3. 삭제 시 재생 중인 파일을 먼저 다음 영상으로 전환하여 파일 잠금 문제를 피한다.
4. 회전은 가능하면 화면 렌더링 단계에서 처리하여 원본 파일을 변경하지 않는다.
5. 처음부터 모든 기능을 넣지 않고 실제 사용하면서 필요한 기능만 추가한다.
